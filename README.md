# SiteRony

Bem-vindo ao SiteRony, o primeiro site criado para o projeto "Rony Eventos e Buffet".

## Sobre
Este site apresenta a identidade visual e as informações essenciais sobre os serviços de buffet e eventos oferecidos por Rony.

## Estrutura do projeto
- `index.html` – página principal do site.
- `style.css` – estilos visuais e layout.
- `img/` – imagens usadas no site.

## Como usar
1. Abra o arquivo `index.html` no seu navegador.
2. Navegue pelo site para ver o layout, as seções e as imagens.

## Tecnologias usadas
- HTML
- CSS

## Objetivo
A proposta deste projeto é criar um site simples e elegante para apresentar serviços de buffet e eventos, funcionando como portfólio e contato inicial.
